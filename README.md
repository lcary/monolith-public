# Monolith

**Monolith** is a competitive software-company engine builder about growing a startup, managing technical debt, shipping products, and trying to reach the IPO before your rivals.

**Play:** https://monolithgame.app

## About this repository

This is the public issue tracker and feedback repository for Monolith.

The game's source code is currently maintained privately. This repository does not contain the Monolith application source.

Use this repository to:

* report bugs
* suggest features
* give gameplay or balance feedback
* report mobile or UI problems

## Report a bug

Found something broken?

[Report a bug](https://github.com/lcary/monolith-public/issues/new?template=bug-report.yml)

Please include what happened, what you expected to happen, and reproduction steps if you know them. Screenshots or short recordings are useful when the problem is visual.

Please don't include passwords, authentication tokens, private account information, or other sensitive data in reports.

## Feedback and feature requests

Ideas about gameplay, balance, usability, or features are welcome.

[Submit feedback or a feature request](https://github.com/lcary/monolith-public/issues/new?template=feature-request.yml)

## Early release

Monolith is under active development. Bugs, balance changes, and rough edges are expected during the current soft-launch period.

If something feels wrong—even if you're not sure whether it's technically a bug—feel free to open an issue.
